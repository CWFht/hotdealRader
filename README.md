# 핫딜 레이더 v1.1

일상생활 전반의 핫딜을 한 화면에서 탐색하는 개인용 핫딜 피드입니다.

## 구성

- `index.html` : GitHub Pages용 메인 화면
- `styles.css` : 모바일 우선 카드형 디자인
- `app.js` : 검색, 필터, 관심저장, 제외어 기능
- `data/deals.json` : 화면에 표시할 핫딜 데이터
- `tools/crawler.py` : 공개 게시판 목록에서 제목/가격/링크 중심으로 수집하는 크롤러
- `.github/workflows/update-deals.yml` : GitHub Actions 자동 수집 워크플로

## 바로 테스트하는 방법

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. GitHub 저장소의 `Settings > Pages`로 이동합니다.
3. Source를 `Deploy from a branch`로 선택합니다.
4. Branch는 `main`, Folder는 `/root`로 선택합니다.
5. 배포 주소로 접속하면 `핫딜 레이더` 화면이 열립니다.

## 자동 수집 사용 방법

1. 저장소의 `Actions` 탭으로 이동합니다.
2. `Update hotdeal data` 워크플로를 선택합니다.
3. `Run workflow`를 눌러 수동 실행해봅니다.
4. 정상 실행되면 `data/deals.json`이 자동 갱신됩니다.

기본 예약 실행은 한국시간 기준 약 09:17, 12:17, 15:17, 18:17, 21:17, 00:17입니다.

## 주의

이 크롤러는 공개 게시글 목록에서 제목, 링크, 가격, 댓글 수 같은 최소 정보만 수집하도록 만든 개인용 예시입니다.

- 로그인 필요한 영역 수집 금지
- CAPTCHA, 차단 우회 금지
- 과도한 요청 금지
- 원문 전체 복제 금지
- 각 사이트의 robots.txt 및 이용약관 확인 권장

## 추천 개선 방향

- 관심 키워드 알림
- 텔레그램/카카오톡 알림
- 쇼핑몰 직링크 추출
- 품절 감지
- 가격 변동 히스토리
- 카테고리별 레이더 점수 보정


## v1.1 변경점

- 육아/출산/임산부/반려동물/뷰티·건강/주방·수납/해외직구 카테고리 확장
- `맘카페픽` 탐색 모드 추가
- 수집처 필터 추가
- 네이버 카페 계열은 기본값 비활성화
  - 공개 접근 가능한 게시판 URL만 확인 후 직접 켤 수 있도록 주석 처리
  - 로그인, CAPTCHA, 차단 우회 방식은 넣지 않음

## 네이버 카페를 다루는 현실적인 방식

맘스홀릭 같은 카페는 육아 핫딜 가치가 크지만, 카페 글은 회원 권한·로그인·게시판 공개 여부에 따라 접근성이 달라집니다.

따라서 이 버전에서는 직접 수집을 기본값으로 켜지 않고,
`tools/crawler.py`의 `SOURCES`에 주석 예시만 넣어두었습니다.

권장 방식:

1. 공개 접근 가능한 게시판 URL인지 브라우저 시크릿 모드에서 먼저 확인
2. 공개 목록에서 제목/링크/시간 정도만 수집
3. 로그인/쿠키/우회 수집은 사용하지 않기
4. 카페 정보는 알림 보조 + 원문 이동 중심으로 활용


## v1.2 변경점

- 화면에 `레이더 점수 기준 보기` 안내 박스 추가

## 레이더 점수 기준

기본 점수 35점에서 시작해 아래 요소를 더하거나 뺍니다.

| 요소 | 반영 |
|---|---:|
| 추천/좋아요 | 최대 +28점 |
| 댓글 반응 | 최대 +18점 |
| 조회수 | 최대 +12점 |
| 무료배송 | +5점 |
| 역대가/특가/체감가/핫딜/쿠폰/무료 키워드 | +8점 |
| 1만원 이하 | +4점 |
| 맘카페픽 | +5점 |
| 품절/종료 | -28점 |

점수는 1~100점 사이로 보정됩니다.

주의: 이 점수는 실제 최저가를 보장하는 절대 기준이 아니라, 커뮤니티 반응과 제목 신호를 바탕으로 “먼저 볼 만한 딜”을 정렬하기 위한 탐색 점수입니다.
