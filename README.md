# 핫딜 레이더

일상생활 전반의 핫딜을 한 화면에서 탐색하는 개인용 핫딜 피드입니다.

## 구성

- `index.html` : GitHub Pages용 메인 화면
- `styles.css` : 모바일 우선 카드형 디자인
- `app.js` : 검색, 필터, 관심저장, 제외어 기능
- `data/deals.json` : 화면에 표시할 핫딜 데이터
- `tools/crawler.py` : 공개 게시판 목록에서 제목/가격/링크 중심으로 수집하는 크롤러
- `.github/workflows/update-deals.yml` : GitHub Actions 자동 수집 워크플로

## 바로 테스트하는 방법

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. GitHub 저장소의 `Settings > Pages`로 이동합니다.
3. Source를 `Deploy from a branch`로 선택합니다.
4. Branch는 `main`, Folder는 `/root`로 선택합니다.
5. 배포 주소로 접속하면 `핫딜 레이더` 화면이 열립니다.

## 자동 수집 사용 방법

1. 저장소의 `Actions` 탭으로 이동합니다.
2. `Update hotdeal data` 워크플로를 선택합니다.
3. `Run workflow`를 눌러 수동 실행해봅니다.
4. 정상 실행되면 `data/deals.json`이 자동 갱신됩니다.

기본 예약 실행은 한국시간 기준 약 09:17, 12:17, 15:17, 18:17, 21:17, 00:17입니다.

## 주의

이 크롤러는 공개 게시글 목록에서 제목, 링크, 가격, 댓글 수 같은 최소 정보만 수집하도록 만든 개인용 예시입니다.

- 로그인 필요한 영역 수집 금지
- CAPTCHA, 차단 우회 금지
- 과도한 요청 금지
- 원문 전체 복제 금지
- 각 사이트의 robots.txt 및 이용약관 확인 권장

## 추천 개선 방향

- 관심 키워드 알림
- 텔레그램/카카오톡 알림
- 쇼핑몰 직링크 추출
- 품절 감지
- 가격 변동 히스토리
- 카테고리별 레이더 점수 보정
