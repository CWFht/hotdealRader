# 네이버 검색 노출 설계

네이버는 순위 공식을 공개하지 않는다. 아래에서 **[공식 방향]**은 네이버가 밝혀 온 평가 방향이고, **[업계 통설]**은 블로거·마케팅 업계의 경험칙이라 수치를 절대 기준으로 삼지 않는다. 판단이 갈리면 "검색한 사람에게 이 글이 실제로 도움이 되는가"로 돌아간다.

## 1. 네이버가 글을 보는 방식

| 축 | 무엇을 보나 | 글 쓸 때 할 일 |
| --- | --- | --- |
| C-Rank [공식 방향] | 블로그(채널)가 특정 주제에서 얼마나 믿을 만한가 | 프로필의 주제 기둥 안에서 쓴다. 기둥을 벗어난 주제는 결과에 "주제 일관성에 불리"라고 알린다 |
| D.I.A.+ [공식 방향] | 문서 자체의 질: 경험·정보의 충실함, 독창성, 검색 의도와의 일치 | 다른 글에 없는 정보 한 가지(연결 키워드, 직접 계산, 비교표)를 반드시 넣는다 |
| 스마트블록 [공식 방향] | 한 검색어를 의도별 블록으로 나눠 노출 | 넓은 키워드보다 의도가 분명한 세부 키워드를 겨냥한다 |
| AI 브리핑 [업계 통설] | 질문에 대한 답을 요약해 인용 | 질문형 소제목 바로 아래에 답을 한두 문장으로 먼저 쓴다 |
| 어뷰징 필터 [공식 방향] | 복사·유사 문서, 키워드 반복, 대량 생산된 저품질 글 | 4장 참고 |

## 2. 키워드 설계

1. **메인 키워드**: 독자가 실제로 치는 말. 2~3어절의 구체적인 조합이 좋다("세탁기" ✗ → "드럼세탁기 냄새 제거" ✓). 신생·중소 블로그는 경쟁이 센 대표 키워드보다 세부 키워드에서 먼저 1페이지를 잡는 편이 빠르다.
2. **연결 키워드**: 메인과 다른 궁금증 하나. 고르는 기준은 "메인 키워드를 검색한 사람이 바로 다음에 검색할 말"이다. 자동완성·연관 검색어·질문형 검색에서 찾는다.
3. **보조 키워드 2~3개**: 소제목과 본문에 자연스럽게 들어갈 연관어.
4. 상위 글 3~5개를 훑어 공통으로 다루는 것(빠지면 안 되는 것)과 아무도 다루지 않는 것(차별점)을 적는다.
5. 검색량은 조회 도구가 없으면 말하지 않는다. 필요하면 사용자가 네이버 검색광고 키워드 도구로 확인하도록 검수 포인트에 적는다.

## 3. 배치 규칙

| 위치 | 기준 | 이유 |
| --- | --- | --- |
| 제목 | 메인 키워드를 앞쪽에. 30자 안팎, 길어도 40자 | 검색 결과에서 뒤가 잘리고, 앞쪽 일치가 클릭 판단에 쓰인다 |
| 제목 형식 | 숫자·방법·대상·결과 중 하나가 보이게 | 얻을 가치가 예측되어야 클릭한다 |
| 도입 첫 문단 | 메인 키워드 1회 + 한 줄 결론 | 들어오자마자 맞게 왔다는 확신을 준다 |
| 본문 | 메인 키워드 4~7회, 문맥이 어색하면 줄인다 | 반복은 어뷰징 신호다. 조사·어순을 바꾼 변형도 섞는다 |
| 소제목 | 3~5개 중 1~2개에 키워드·연관어. 질문형·조건형을 섞는다 | 훑어 읽는 독자의 길잡이이자 AI 브리핑의 인용 단위 |
| 표·목록 | 비교는 표, 절차는 번호 | 스캔이 쉬워 체류와 스크롤이 늘어난다 |
| 이미지 | 내용 전환점마다 1장, 글 전체 5~10장 [업계 통설] | 모바일에서 글만 이어지면 이탈한다. 장수보다 본문과의 관련성이 중요 |
| 태그 | 5~10개. 메인·연결·보조 키워드와 상위 카테고리어 | 태그는 검색보다 주제 분류에 쓰인다 |
| 분량 | 프로필 기준. 기본 1,400~1,800자(공백 제외) | 길이가 아니라 의도 해결이 기준. 채우기용 문단은 뺀다 |
| 약속 | 제목이 말한 것을 본문이 전부 답한다 | 낚시 제목은 이탈을 만들고 블로그 신뢰를 깎는다 |

## 4. 저품질·어뷰징으로 읽히는 것

- 같은 키워드를 문장마다 넣거나, 뜻 없는 키워드 나열 문단을 붙이는 것
- 다른 글·뉴스·상세페이지를 옮겨 적거나 문장만 바꾼 것 (출처 사실은 내 말로 다시 쓰고 판단을 덧붙인다)
- 같은 틀·같은 문장으로 찍어낸 글을 연달아 올리는 것. 그래서 글마다 도입 방식과 소제목 형태를 다르게 한다
- 본문과 상관없는 이미지, 다른 글에 썼던 이미지의 재사용
- 숨긴 텍스트, 본문과 무관한 태그
- 광고 글만 이어지는 블로그. 프로필의 정보성:수익성 비율을 지킨다 (기본 3:1 이상 [업계 통설])

AI로 썼다는 사실 자체보다 **가치 없이 대량 생산된 글처럼 보이는 것**이 문제다. 그래서 이 봇은 글마다 조사하고, 확인한 사실과 구체적인 수치를 넣고, 사람이 검수하는 흐름을 지킨다.

## 5. 주제 묶음으로 쓰기

글 한 편의 순위는 블로그가 그 주제에서 쌓은 신뢰에 기대므로, 한 주제를 글 하나로 끝내지 않고 3~5편 묶음으로 설계한다.

- 기둥 글 1편(넓은 질문에 답하는 정리 글) + 가지 글 여러 편(세부 질문 하나씩).
- 납품할 때 "다음에 이어 쓸 글" 1~2개를 제안한다. 같은 묶음의 글이 쌓이면 서로 내부 링크로 잇는다.
- 내부 링크는 사용자가 예전 글 URL을 준 경우에만 넣는다. 없는 글로 링크를 만들지 않는다.

## 6. 발행 뒤 (사용자에게 알려 줄 것)

- 발행 직후 여러 번 수정하지 않는다. 고칠 것은 붙여넣기 전에 끝낸다.
- 댓글에 답하면 상호작용 신호가 쌓인다. 마무리 질문이 그 재료다.
- 발행 1~2주 뒤 블로그 통계의 유입 검색어를 보고, 예상과 다른 검색어로 들어오면 그 검색어로 가지 글을 쓴다.
