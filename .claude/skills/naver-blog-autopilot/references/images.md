# 이미지 계획과 제작

이미지는 장식이 아니라 본문의 한 문단을 대신하는 정보다. 그 자리에서 독자가 무엇을 한눈에 봐야 하는지를 먼저 정하고, 그다음 제작 방식을 고른다.

## 1. 방식 고르기

| 방식 | 쓰는 경우 | 만드는 법 |
| --- | --- | --- |
| 디자인 카드 | 글자·숫자가 정확해야 하는 것: 썸네일, 핵심 요약, 비교표, 단계 안내, 체크리스트 | `cards.json` 작성 → `render_cards.py` |
| GPT 이미지 | 분위기·상황 컷: 도입의 생활 장면, 개념을 빗댄 그림, 썸네일 배경 | `gpt_images.json` 작성 → `gpt_images.py` |
| 실물 자리 | 제품 실물, 실제 화면 캡처, 사용 장면 | 본문에 마커만 넣고 사용자가 채운다. 공식 이미지를 받았으면 `images/`에 넣고 번호를 맞춘다 |

고르는 기준:
- **글자가 들어가면 카드.** 이미지 생성 모델은 한글을 자주 틀리게 그린다. 표·수치·절차는 카드로 만든다.
- **실제 물건·화면은 실물.** AI로 그린 제품 사진이나 앱 화면은 실제와 달라 독자를 속이게 되고, 브랜드커넥트 글에서는 오인 광고 소지가 있다.
- **GPT 이미지는 글자 없이.** 프롬프트에 "이미지 안에 글자·로고·워터마크 없음"을 넣는다. 문구가 필요하면 글자 없는 배경을 받아 카드의 `background`로 쓴다.
- 기본 구성은 썸네일 1 + 본문 5~8장. 프로필에 장수가 정해져 있으면 그것을 따른다.
- 다른 글에 쓴 이미지를 다시 쓰지 않는다. 카드도 글마다 내용이 달라야 한다.

## 2. 마커와 파일 번호

- 본문 마커: `📷 이미지 03 │ 용량별 전기료 비교 카드`
- 파일명: `images/03_용량별전기료.png` — 앞의 두 자리 번호가 마커 번호와 같아야 한다. 썸네일은 `00_썸네일.png`.
- 실물 자리는 마커 설명 끝에 `(직접 촬영)` 또는 `(공식 이미지)`를 붙여 사용자가 채울 자리임을 알린다.

## 3. cards.json

```json
{
  "brand": {"name": "가전적인남편", "color": "#1f6feb", "font": "Gmarket Sans"},
  "out_dir": "images",
  "cards": [
    {"file": "00_썸네일.png", "type": "thumbnail", "kicker": "건조기 용량", "title": "9kg vs 16kg\n뭐가 다를까", "sub": "4인 가족 기준 정리"},
    {"file": "01_핵심요약.png", "type": "list", "title": "3줄 요약", "items": ["이불 빨래를 하면 16kg", "1~2인 가구는 9kg로 충분", "설치 공간 폭 60cm 먼저 확인"]},
    {"file": "02_단계.png", "type": "list", "numbered": true, "title": "설치 전 확인 순서", "items": ["배수 위치", "문 열림 방향", "직렬 설치 가능 여부"]},
    {"file": "03_비교표.png", "type": "table", "title": "용량별 비교", "head": ["구분", "9kg", "16kg"], "rows": [["권장 가구", "1~2인", "3~4인"], ["이불", "홑이불", "킹 이불"]], "note": "제조사 공식 사양 기준 (2026-11)"}
  ]
}
```

- `type`: `thumbnail`(1024×1024), `list`·`table`(1536×1024).
- 카드 문구는 짧게. 제목 14자 안팎, 항목은 한 줄 20자 안팎, 항목 5개 이하, 표는 5행 4열 이하. 넘치면 카드를 나눈다.
- 카드의 숫자·사실은 본문과 똑같아야 한다. 본문을 고치면 카드도 다시 만든다.
- 표 카드에는 `note`에 기준과 날짜를 적는다.
- `background`에 이미지 경로를 주면 썸네일 배경으로 깔린다.
- 렌더링 뒤 PNG를 직접 열어 글자 넘침·잘림을 확인한다. 브라우저가 없는 환경에서는 HTML만 만들어지며, 그 사실을 결과에 알린다.

## 4. gpt_images.json

```json
{
  "out_dir": "images",
  "style": "밝은 자연광, 한국 가정집, 실사 사진 느낌, 차분한 색감",
  "images": [
    {"file": "04_빨래더미.png", "size": "1536x1024", "prompt": "세탁실 바닥에 쌓인 이불과 수건 더미, 옆에 빈 빨래 바구니", "alt": "쌓인 빨래 더미"}
  ]
}
```

- `gpt_images.py`는 항상 `GPT_이미지_프롬프트.md`를 만든다. 사용자가 ChatGPT에 그대로 붙여 넣어 만들 수 있는 형태다.
- 환경에 `OPENAI_API_KEY`가 있으면 이미지까지 생성해 `images/`에 저장한다. 없으면 프롬프트 파일만 납품하고 검수 포인트에 "GPT로 이미지 N장 생성 필요"를 적는다.
- 프롬프트 쓰는 법: 장면(무엇이 어디에) → 구도(가로, 여백 위치) → 스타일 순서. 사람 얼굴 클로즈업, 실제 브랜드 로고, 특정 제품 모양은 넣지 않는다.
- 한 글 안의 이미지는 `style`을 같이 써서 톤을 맞춘다.

## 5. 프로필의 이미지 규칙

프로필에 프레임, 도장, 서체, 규격이 정해져 있으면 그것이 우선이다. 프로필이 요구하는 원본 파일(도장, 서체)이 작업 환경에 없으면 비슷하게 그려 내지 말고, 없는 채로 만든 뒤 검수 포인트에 무엇이 빠졌는지 적는다.
